# University Extension & Late Submission Policy (Example)

This file is read directly by the workflow and used as the ONLY source of truth
for policy decisions. Edit it to match your actual course policy — do not
rely on the LLM's own judgment beyond what is written here.

## Assignment Extensions

- **Medical reason** (illness, injury, hospitalization): grant a **3-day**
  extension automatically. Politely ask the student to keep any medical
  documentation on file in case the department requests it later, but do not
  require it up front.
- **Personal/family emergency**: grant a **2-day** extension, and request
  supporting documentation (e.g. a note from a guardian, dean's office email)
  within 5 days.
- **Technical issues** (e.g. "my laptop crashed", "internet was down"):
  grant a **1-day** extension only, and note that technical issues are the
  student's responsibility to plan around in the future.
- **Workload / time management** ("I have too many assignments", "I forgot"):
  **do not grant** an extension. Politely explain that this is not covered
  by policy and point them to the syllabus late-penalty policy.

## Late Submissions (already past deadline)

- If the reason is medical or a documented personal emergency and the
  submission is **within 3 days** of the deadline: accept it with **no
  penalty**, subject to providing documentation within 5 days.
- If more than 3 days late for any reason: the agent should **not** approve
  automatically. Draft a reply saying the request has been forwarded to the
  professor for manual review, and do not state a decision.

## Grade Clarification Requests

- The agent does **not** have authority to change or discuss specific grades.
- Draft a reply acknowledging the request, asking the student to specify
  which assignment/question they'd like reviewed, and letting them know the
  professor will respond directly with detail. Do not speculate on grading.

## General Rules

- Always be polite, concise, and professional.
- Always ask for the student's roll number and course code if missing.
- Never promise something outside this document (e.g. do not invent grace
  periods, do not waive penalties not listed here).
- All drafts are reviewed by the professor before sending — the agent should
  write as if it is speaking *on behalf of* the professor, in first person
  plural ("we", "our department") or neutral tone, not impersonating the
  professor by name.
