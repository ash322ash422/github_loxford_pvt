Customer Support Handbook

Welcome to the Northstar Workspace help center. This fictional article explains billing, account security, document uploads, and support requests. Use the section headings to locate the relevant policy before making a change.

Billing and Subscriptions

Workspace owners manage plans, payment methods, and invoices from the billing page. Before changing plans, review the features and storage limits your team currently needs.

Canceling a Subscription

Cancellation stops the next renewal. Paid features remain available until the current billing period ends, after which the free plan limits apply.

  1. Open Settings and select Billing.
  2. Choose Cancel subscription and review the effective date.
  3. Confirm the cancellation and save the confirmation email.

Uninstalling the application does not cancel a subscription. If another workspace owner manages billing, coordinate with that owner before making changes.

Refund Requests

Cancellation does not automatically issue a refund. Contact billing support within fourteen days of the original purchase and provide the invoice number and reason for the request.

For a duplicate charge, include the dates and amounts of both transactions. Never include a complete card number in an ordinary support message.

Account Security

Use a unique password and enable two-factor authentication. Give each team member an individual account so changes can be attributed to the correct person.

Recovering Access

If an authenticator device is lost, use a saved recovery code. Each code works only once. Enroll a replacement device and generate fresh codes after signing in.

If both the device and recovery codes are unavailable, contact account support for identity verification. Support cannot skip verification because the request is urgent. Never send a password or recovery code in a ticket.

Reviewing Permissions

Review workspace membership every month. Remove former employees and external collaborators who no longer need access. Limit billing permissions to the people who manage purchases.

  • Viewers read shared documents.
  • Editors update documents in assigned projects.
  • Owners manage membership, billing, and settings.

Document Uploads

Upload PDF or plain text documents up to twenty megabytes per file. Scanned PDFs may need optical character recognition. Upload completion and search availability are separate stages.

Troubleshooting Upload Failures

Compress or divide files that exceed the size limit. For smaller files, verify the format, unlock password-protected PDFs, and retry after the connection is stable.

Failed uploads do not consume the document processing quota. Check the status of an earlier attempt before uploading the same file again.

Processing and Search Availability

The document status progresses from Uploaded to Processing and then Searchable. Complex layouts and large files can take longer to process than short plain text documents.

Once processing completes, test a question with a known answer from the file. Inspect extracted text for empty pages, missing tables, or incorrect reading order if the answer cannot be found.

Contacting Support

Include the workspace identifier, the time of the problem, and a description of expected and actual behavior. Remove private customer information from screenshots before attaching them.

Reporting a Service Incident

Check the service status page first. If no incident is listed, report the affected feature, number of users, and error message. Send security concerns through the dedicated security channel.

Following Up on a Ticket

Reply to the existing ticket rather than opening duplicate requests. Mention whether the problem occurs in another browser or on another network, and keep the ticket number for reference.
