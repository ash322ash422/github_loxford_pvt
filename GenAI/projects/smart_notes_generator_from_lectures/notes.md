# Introduction to Retrieval Augmented Generation (RAG)

## Summary
Retrieval Augmented Generation (RAG) is a powerful framework designed to enhance the capabilities of Large Language Models (LLMs). It achieves this by integrating private knowledge bases, thereby improving factual accuracy and contextual relevance in generated responses. The RAG process is structured into three distinct phases: Ingestion, Retrieval, and Generation, each playing a crucial role in leveraging external data.

## Retrieval Augmented Generation (RAG)
- Framework that enhances Large Language Model (LLM) capabilities.
- Integrates private knowledge bases.
- Improves factual accuracy and contextual relevance.

## RAG Phases
- Three main phases: Ingestion, Retrieval, and Generation.
- Ingestion: Populating the vector database.
- Retrieval: Retrieving relevant chunks from the vector database to answer a question.
- Generation: Generating an answer from the retrieved chunks.

## Key Terms
- **RAG**: Retrieval Augmented Generation
- **Ingestion (RAG)**: The process of populating a vector database with data.
- **Retrieval (RAG)**: The process of fetching relevant data chunks from a vector database based on a query.
- **Generation (RAG)**: The process of formulating an answer using the retrieved data chunks and an LLM.
